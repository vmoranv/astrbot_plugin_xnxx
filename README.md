# AstrBot XNXX 插件

AstrBot 的 XNXX 视频信息查询插件，支持获取视频详情、搜索视频和用户信息。

## 功能特性

- 📹 **视频信息查询**: 根据视频ID获取详细的视频信息
- 🔍 **视频搜索**: 支持关键词搜索视频
- 👤 **用户信息**: 获取用户/演员的详细信息
- 🖼️ **缩略图处理**: 支持自动下载和模糊处理视频封面
- 🧹 **自动清理**: 每次发送消息前自动清理上一次的缓存文件
- ⚙️ **可配置**: 支持配置代理地址和模糊程度

## 安装

1. 将插件文件夹放入 AstrBot 的 `data/plugins/` 或 `packages/` 目录
2. 在 AstrBot 中启用插件
3. 插件会自动安装依赖

## 配置

在插件配置中可以设置以下选项：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `proxy_url` | 代理地址，用于访问XNXX | 空 |
| `blur_level` | 图片模糊程度（0=不模糊），数值越大模糊程度越高 | 80 |

## 使用方法

### 查询视频信息

```
/xnxx <视频ID>
```

示例：
```
/xnxx abc123def456
```

### 搜索视频

```
/xnxx_search <关键词>
```

示例：
```
/xnxx_search 关键词
```

### 获取用户信息

```
/xnxx_user <用户URL或ID>
```

示例：
```
/xnxx_user https://www.xnxx.com/pornstars/username
```

或直接使用用户名：
```
/xnxx_user username
```

## 命令说明

| 命令 | 说明 | 参数 |
|------|------|------|
| `/xnxx` | 查询视频信息 | 视频ID |
| `/xnxx_search` | 搜索视频 | 搜索关键词 |
| `/xnxx_user` | 获取用户信息 | 用户URL或ID |

## 注意事项

1. 插件需要安装 `xnxx-api` 依赖，会自动安装
2. 每次执行命令前会自动清理上一次的缓存文件
3. 视频封面会根据配置的模糊程度自动处理
4. 所有消息末尾添加了零宽字符 `\u200E` 以防止被 `.strip()` 截断
5. 视频ID只需提供ID部分，URL前缀会自动添加

## 依赖

- `xnxx-api>=1.0.0` - XNXX API 客户端
- `Pillow>=10.0.0` - 图像处理库
- `aiohttp>=3.8.0` - 异步HTTP客户端
